# ระบบรายงานสถานะเหตุการณ์และเฝ้าระวังพื้นที่ผ่านแผนที่ดาวเทียม (ERM)
**Satellite Incident & Situation Monitoring System**

ระบบแดชบอร์ดรายงานสถานการณ์และเฝ้าระวังพื้นที่โดยใช้ภาพถ่ายดาวเทียมความละเอียดสูง (Google Satellite & Esri World Imagery) แสดงหมุดพร้อมป้ายข้อความสรุปสถานะทันทีบนแผนที่ (ไม่ต้องคลิกดู) รองรับการป้อนข้อมูล 3 กลุ่มเหตุการณ์หลัก และฟังก์ชันส่งออกภาพสรุปรายงานสำหรับผู้บริหาร

---

## 🌟 จุดเด่นของระบบ (Key Features)

1. **แสดงข้อมูลจุดนั้นได้ทันทีบนแผนที่ (Permanent Callout Badges):**
   - หมุดทุกจุดมีป้ายการ์ดลอยแสดงชื่อจุด, ระดับสถานะ (เขียว/ส้ม/แดง), และข้อความสรุปสถานะสั้นๆ ให้เห็นบนแผนที่ทันทีโดยไม่ต้องคลิก
   - มีลูกศรชี้พิกัดพร้อมวงแหวนสถานะเรืองแสง (Pulsing Indicator)
2. **ภาพถ่ายดาวเทียมความละเอียดสูงโดยไม่ต้องใช้ API Key:**
   - ใช้ Leaflet ร่วมกับ Google Satellite Hybrid Tiles (`lyrs=y`) มีเส้นทางและชื่อสถานที่คมชัด
   - สามารถสลับเลเยอร์เป็น Google Satellite แบบภาพล้วน, Esri World Imagery หรือแผนที่ถนนได้
3. **ติดตาม 3 กลุ่มเหตุการณ์สำคัญ:**
   - 🌊 **คลองสาธารณะ:** ระดับน้ำคลองรอบโรงงาน, ประตูระบายน้ำ, อัตราการไหล
   - ⚠️ **เหตุการณ์รอบและภายในโรงงาน:** การจราจรหน้าทางเข้า, จุดกลับรถ, น้ำท่วมขังรอระบาย
   - 🏭 **คุณภาพน้ำและกำลังการผลิต:** ปริมาณการผลิตน้ำ (ลบ.ม./วัน), ความขุ่น (NTU), คลอรีน, ค่า pH
4. **📸 ฟังก์ชันบันทึกภาพรายงานผู้บริหาร (Executive Report Image Export):**
   - เพียงคลิกปุ่มเดียว ระบบจะรวมภาพแผนที่ดาวเทียม, หมุดข้อความ, หัวกระดาษทางการ, วันที่-เวลาประทับ และแถบสรุปตัวเลขสถิติ (KPIs) ออกมาเป็นไฟล์ภาพ PNG ความละเอียดสูง พร้อมส่งต่อทาง Line หรือสไลด์ประชุมได้ทันที
5. **ระบบจัดการข้อมูลสำหรับผู้ดูแล (Admin Management):**
   - เข้าสู่ระบบด้วย: **ชื่อผู้ใช้:** `admin` | **รหัสผ่าน:** `admin`
   - คลิกบนแผนที่เพื่อปักหมุดจุดใหม่ได้ทันที
   - สามารถลากหมุด (Drag & Drop) เพื่อปรับตำแหน่งพิกัดได้อย่างแม่นยำ
   - แก้ไข/ลบข้อมูล หรือแนบรูปภาพสถานที่จริงได้
6. **เชื่อมต่อฐานข้อมูล Firebase Cloud Firestore (Real-time Sync):**
   - รองรับการเชื่อมต่อกับ Firebase โปรเจกต์ `mwa-erm` แบบ Real-time ผ่าน Cloud Firestore
   - ทุกครั้งที่มีการรายงานเหตุการณ์ใหม่ ปักหมุด หรือลบรายการ ข้อมูลจะอัปเดตบนหน้าจอของผู้ใช้ทุกคนพร้อมกันทันที
   - มีระบบ **Offline Fallback (LocalStorage)** ทำงานได้ลื่นไหลแม้ออฟไลน์หรือยังไม่ได้ใส่ API Key
   - มีปุ่ม **"นำเข้าข้อมูลเริ่มต้นเข้า Firebase"** ในคลิกเดียว ช่วยส่งข้อมูลจุดตรวจการณ์ 17 จุด และประวัติ Timeline เดิมขึ้นคลาวด์ทันที

## 🚀 วิธีการติดตั้งและใช้งาน (Getting Started)

### 1. ใช้งานบนเครื่องคอมพิวเตอร์ (Localhost / XAMPP)
- วางโฟลเดอร์นี้ไว้ใน `C:\xampp\htdocs\ERM` หรือ `D:\xampp\htdocs\ERM`
- เปิด Apache ใน XAMPP Control Panel
- เข้าใช้งานผ่านเว็บเบราว์เซอร์ที่: `http://localhost/ERM/`

### 2. การ Deploy สู่ Cloudflare Pages หรือ GitHub Pages
1. อัปโหลดโค้ดทั้งหมดในโฟลเดอร์นี้ขึ้น **GitHub Repository**
2. ใช้งานบน **GitHub Pages** (Settings > Pages > Branch main) หรือ **Cloudflare Pages**
3. ระบบจะทำงานได้ 100% ทันที

### 3. การตั้งค่า Firebase Cloud Firestore (mwa-erm)
1. เข้าไปที่ [Firebase Console: mwa-erm](https://console.firebase.google.com/u/0/project/mwa-erm/overview)
2. เมนู **Build > Firestore Database** กดปุ่ม **Create database**
3. เลือก Location เช่น `asia-southeast1` (Singapore) และเลือก **Start in test mode**
4. ไปที่ **Project Settings (⚙️)** > เลื่อนลงที่ **Your apps** > คลิกไอคอน **Web (</>)**
5. นำค่า `firebaseConfig` มาใส่ในไฟล์ `js/firebase-config.js` หรือคลิกปุ่ม **"Firebase"** บนแถบเมนูของระบบเพื่อวางค่าและบันทึก
6. กดปุ่ม **"🚀 นำเข้าข้อมูลเริ่มต้นเข้า Firebase"** เพื่อซิงค์ 17 จุดตรวจการณ์และข้อมูลเดิมขึ้นคลาวด์

## 🌟 ฟังก์ชันการทำงานหลักของระบบ ERM

1. **จุดตรวจการณ์มาตรฐาน 17 ตำแหน่ง (+ จุดกำหนดเองบนแผนที่):**
   - DPS, TPS, RPS1, RPS2, MH Phase 1 - 4
   - ถนนจุดจอดรถหน้า Surge Tower (`13.808077, 100.409715`)
   - Raw Water Basin, รส.บางเลน, จุดรับน้ำดิบท่าม่วง, ถนน Workshop
   - จุดกลับรถหน้าโรงงานฯ, จุดกลับรถหน้า ซ.วัดศรีประวัติ, หน้าโรงงาน, 7-11 กลาง ซ.วัดศรีประวัติ
   - คลิกบนแผนที่เพื่อปักหมุดจุดใหม่ได้อิสระ
2. **หน้าจอ Split-Screen (แผนที่ซ้าย + ฟีดอัปเดตขวา):**
   - ฝั่งซ้าย: แผนที่ดาวเทียมความละเอียดสูง (Google Hybrid / Esri / OSM)
   - ฝั่งขวา: แถบ Live Updates แสดงเหตุการณ์เรียงลำดับจากล่าสุด คลิกการ์ดเพื่อบินไปยังจุดนั้นบนแผนที่
3. **ไดอารีไทม์ไลน์ประจำจุด (Location Diary Timeline):**
   - คลิกที่หมุดเพื่อเปิดประวัติการรายงานสถานการณ์แบบไทม์ไลน์ย้อนหลัง
   - แสดง วันที่-เวลา, ชื่อผู้รายงาน, IP Address, ระดับสถานะ (ปกติ/เฝ้าระวัง/วิกฤต), รายละเอียด, และภาพถ่าย
4. **ตรวจจับ IP Address และระบุชื่อผู้รายงาน:**
   - ผู้รายงานระบุชื่อตนเองในการรายงาน
   - ระบบตรวจจับ Client IP Address อัตโนมัติเพื่อบันทึกเป็นประวัติความโปร่งใส
5. **บันทึกภาพถ่าย JPG (Client-side Resize):**
   - บีบอัดภาพถ่ายให้อยู่ในฟอร์แมต JPG ความละเอียดสูงแต่ประหยัดพื้นที่จัดเก็บ
   - มี Lightbox ขยายดูภาพเต็มจอ และปุ่มดาวน์โหลดไฟล์ JPG
6. **รองรับ GitHub Pages และ XAMPP 100%:**
   - ทำงานได้ทั้งแบบ Static (HTML5 / LocalStorage) บน GitHub Pages
   - มีปุ่ม "ส่งออก JSON" / "นำเข้า JSON" สำหรับ commit ขึ้น Git Repository ได้ทันที
